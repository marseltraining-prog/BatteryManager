# BatteryManager for macOS

Современный менеджер батареи для MacBook с управлением зарядкой и мониторингом состояния.

## Возможности

- ⚡ Ограничение максимального заряда батареи
- 📊 Визуализация потребления энергии в реальном времени
- 📈 Графики заряда, температуры и потребления за 24 часа
- 🔥 Защита от перегрева с автоматическим отключением зарядки
- 💚 Мониторинг здоровья батареи
- 🎨 Современный Liquid Glass дизайн

## Системные требования

- macOS 13 Ventura или новее
- Apple Silicon или Intel процессор

## Технологии

- Swift + SwiftUI
- IOKit для доступа к данным батареи
- SMJobBless для привилегированного управления зарядкой
- Swift Charts для графиков

## Разработка и тесты

Среда разработки ограничена: полный Xcode не установлен, а песочница
запрещает запись module cache компилятора в `/var/folders`, из-за чего
`swift test` не может скомпилировать манифест пакета. Поэтому тесты
запускаются напрямую через `swiftc` с module cache внутри репозитория:

```bash
scripts/run-tests.sh
```

Тесты написаны на Swift Testing (`import Testing`). При установке
полноценного Xcode тот же набор заработает и через `swift test`.
