# Дизайн BatteryManager - Liquid Glass Style

## Концепция дизайна

**Liquid Glass** - современный стиль с полупрозрачными элементами, размытием фона (blur), мягкими градиентами и эффектом глубины.

## Цветовая палитра

### Поверхности (Liquid Glass эффект)
- **Surface 1 (deepest):** `rgba(5, 7, 12, 0.85)` - основной фон с 85% непрозрачностью
- **Surface 2:** `rgba(10, 13, 18, 0.75)` - карточки и панели с 75% непрозрачностью
- **Surface 3:** `rgba(15, 19, 28, 0.65)` - элементы управления с 65% непрозрачностью
- **Surface 4:** `rgba(22, 29, 43, 0.55)` - ховер-состояния с 55% непрозрачностью
- **Surface 5 (lightest):** `rgba(30, 38, 54, 0.45)` - акценты с 45% непрозрачностью

### Акцентные цвета
- **Зарядка (зеленый):** `#6EE7B7` (luminous emerald)
- **Разрядка (синий):** `#38BDF8` (cyan accent)
- **Предупреждение (желтый):** `#FBBF24` (warm amber)
- **Критическое (красный):** `#F87171` (soft red)
- **Перегрев (оранжевый):** `#FB923C` (warm orange)

### Градиенты (для графиков и индикаторов)
- **Заряд:** `linear-gradient(135deg, #6EE7B7 0%, #10B981 100%)`
- **Температура нормальная:** `linear-gradient(135deg, #38BDF8 0%, #3B82F6 100%)`
- **Температура предупреждение:** `linear-gradient(135deg, #FBBF24 0%, #F59E0B 100%)`
- **Температура критическая:** `linear-gradient(135deg, #FB923C 0%, #F87171 100%)`

## Эффекты

### Backdrop Blur
- **Основное окно:** `blur(40px)` + `brightness(1.1)` + `saturation(1.2)`
- **Карточки:** `blur(20px)` + `brightness(1.05)`
- **Кнопки:** `blur(15px)`

### Тени (многослойные для глубины)
```swift
// Внешняя тень
.shadow(color: Color.black.opacity(0.3), radius: 20, x: 0, y: 10)
// Внутренняя подсветка
.shadow(color: Color.white.opacity(0.05), radius: 1, x: 0, y: 1)
```

### Borders (стеклянный эффект)
```swift
.overlay(
    RoundedRectangle(cornerRadius: 16)
        .stroke(
            LinearGradient(
                colors: [
                    Color.white.opacity(0.2),
                    Color.white.opacity(0.05)
                ],
                startPoint: .topLeading,
                endPoint: .bottomTrailing
            ),
            lineWidth: 1
        )
)
```

- **Размер:** 420x680 пикселей

- **Радиус:** 24px
- **Padding:** 20px

## Типографика

### Шрифты
- **Основной:** SF Pro Display (системный для macOS)
- **Моноширинный (цифры):** SF Mono
- **Размеры:**
  - Display: 32px, weight: bold
  - Title: 20px, weight: semibold
  - Body: 15px, weight: regular
  - Caption: 13px, weight: medium
  - Mono: 14px (для технических данных)

### Межстрочный интервал
- Display: 1.1
- Body: 1.4
- Caption: 1.3

## Анимации

### Переходы между вкладками
- **Duration:** 0.3s
- **Easing:** easeInOut
- **Effect:** fade + slight slide (10px)

### Изменение значений
- **Duration:** 0.5s
- **Easing:** spring (damping: 0.7)

### Пульсация при зарядке
- **Duration:** 2.0s
- **Repeat:** infinite
- **Effect:** opacity 80% → 100% → 80%

### Предупреждения
- **Duration:** 0.8s
- **Repeat:** 3 раза
- **Effect:** shake + color pulse

## Состояния компонентов

### Кнопки
- **Default:** Surface 3 + border gradient
- **Hover:** Surface 4 + glow(5px)
- **Active:** Surface 2 + scale(0.95)
- **Disabled:** Surface 2 + opacity(0.5)

### Слайдер
- **Track:** Surface 3, height: 8px
- **Progress:** зеленый градиент
- **Thumb:** белый круг 20px с тенью
- **Thumb hover:** scale(1.2) + glow

## Адаптивность

### Светлая тема (если пользователь не использует темную)
- Инвертировать Surface (светлые вместо темных)
- Сохранить акцентные цвета
- Уменьшить blur для читаемости

### Accessibility
- Все цвета проходят WCAG AA для контрастности
- Поддержка VoiceOver
- Увеличенные hit targets (минимум 44x44px)
- Поддержка Reduce Motion (отключить анимации)
