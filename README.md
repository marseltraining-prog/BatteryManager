# BatteryManager for macOS

Менеджер батареи для MacBook: мониторинг состояния, история и графики,
защита от перегрева, иконка Dock с процентом заряда.

## Возможности

- 🔋 Процент заряда в строке меню и на иконке в Dock (цвет по состоянию)
- 📊 Визуализация: заряд, температура, мощность адаптера и системы
- 📈 История за 24 часа на SQLite + три графика (Swift Charts)
- 🔥 Защита от перегрева: предупреждение 35-40°C, отключение заряда выше 40°C
- 💚 Здоровье батареи: ёмкости, износ, циклы, состояние
- 🎚️ Лимит заряда 20–100% и ручные режимы (нужен helper, см. ниже)
- 🎨 Liquid Glass дизайн (полупрозрачные поверхности, градиенты, тени)

## Системные требования

- macOS 13 Ventura или новее
- Apple Silicon или Intel процессор

## Технологии

- Swift + SwiftUI, Swift Charts
- IOKit (реестр `AppleSmartBattery` / `AppleSmartBatteryPack`) — данные батареи
- SQLite3 (системный) — история за 24 часа
- AppKit (Dock tile, `NSPanel`) — иконка Dock и панель приложения
- SMC через IOKit — управление зарядкой (свой C-слой: AppleSMC требует
  точной раскладки структуры, которую Swift не гарантирует)

## Использование

```bash
scripts/build-app.sh          # собрать build/BatteryManager.app
scripts/build-app.sh --run     # собрать и запустить
```

После запуска:

- в **строке меню** появляется процент заряда — клик открывает окно
  с вкладками «Статус», «Графики», «Здоровье», «Настройки»;
- на **иконке в Dock** виден процент заряда и цвет состояния
  (зелёный — зарядка, белый — разрядка, янтарный ⚠️ — нагрев,
  красный 🔥 — критический перегрев); клик по иконке открывает панель;
- история пишется в
  `~/Library/Application Support/BatteryManager/history.db` раз в минуту.

## Разработка и тесты

Сборка идёт без Xcode, через Command Line Tools: архитектура и SDK
берутся с машины сборки, минимальная система приложения — macOS 13.
Песочница запрещает запись module cache компилятора в `/var/folders`,
из-за чего `swift test` не может скомпилировать манифест пакета. Поэтому тесты
запускаются напрямую через `swiftc` с module cache внутри репозитория:

```bash
scripts/run-tests.sh
```

Тесты написаны на Swift Testing (`import Testing`). При установке
полноценного Xcode тот же набор заработает и через `swift test`.

## Ограничение заряда

Запись в SMC требует прав root, поэтому зарядом управляет небольшой
helper (`Sources/Helper/helper.c`): он ставится один раз и принимает
только три команды — `hold`, `allow`, `status`.

Установка (macOS спросит пароль администратора):

```bash
open Установка-Helper.command
```

После установки на вкладке «Статус» становятся активными:

- **слайдер лимита** 20–100% (100% — ограничение выключено); лимит
  сохраняется между запусками;
- **«Разряд»** — зарядка отключена, пока режим не отменён;
- **«Заряд»** — заряд до 100% без учёта лимита, на 100% режим выключается сам;
- строка состояния: успех показывается только после подтверждения helper,
  отказ — с текстом ошибки и кнопкой «Повторить».

Как это устроено:

- удержание снимается на 2% ниже лимита (лимит 80% → зарядка вернётся на 78%),
  чтобы адаптер не переключался на каждом проценте;
- перегрев (>40°C) останавливает зарядку в любом режиме; после остывания
  действует лимит, а не безусловная зарядка;
- перед сном и при выходе из приложения удержание снимается: команда
  живёт в SMC сама по себе, и без работающего приложения её некому
  отменить. Следствие: за долгий сон на зарядке Mac может зарядиться
  выше лимита;
- если приложение завершилось аварийно, удержание снимается (или
  восстанавливается по лимиту) при следующем запуске.

Что известно об этой машине (Mac16,12, macOS 27):

- ключей `CHTE`, `CH0B`/`CH0C` в SMC нет, `CHSC` защищён от записи;
- управляющий ключ — `CHIE`: значение `08` отключает адаптер, и Mac
  работает от батареи; `00` возвращает питание. То есть «удержание» здесь —
  это работа от батареи при подключённом адаптере, а не пауза зарядки.

Не проверено: работа helper под root на реальной машине после установки
(сборка и чтение ключей проверены, запись — нет). Если установлен AlDente,
его нужно закрыть: два приложения будут перебивать команды друг друга.

Что осталось:

- проверка helper под root на реальной машине;
- английская локализация, VoiceOver и Reduce Motion;
- подпись Developer ID и нотаризация (нужны Xcode и аккаунт разработчика).
